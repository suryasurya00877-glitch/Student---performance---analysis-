# l  Student Performance Analysis & Prediction

A Machine Learning project developed using Python to analyze and predict student academic performance based on study habits and past exam results.

##  Project Overview
The objective is to identify key factors impacting academic success and predict final exam scores using Multiple Linear Regression.

##  Tech Stack
- **Language:** Python
- **Environment:** Google Colab
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn

##  Features & Target
- **Features (Input):**
  - `Study_Hours`: Daily study duration (hours)
  - `Attendance_Perc`: Class attendance percentage
  - `Past_Exam_Score`: Previous exam marks
- **Target (Output):**
  - `Final_Score`: Predicted final exam marks

##  Key Results
- **Algorithm:** Multiple Linear Regression
- **Accuracy (R² Score):** 98.37%
- **Sample Prediction:** 
  - Input: 6 hrs study, 85% attendance, 75 past score
  - Predicted Score: **78.92**
